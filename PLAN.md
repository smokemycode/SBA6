# Project Plan

## API
- Base URL: https://dummyjson.com/products
- Single product: https://dummyjson.com/products/{id}

## Steps
1. Create Product class with properties matching API
2. Create discount calculator (returns dollar amount)
3. Create tax calculator (4.75% default, 3% for groceries)
4. Create custom error classes
5. Create API service with async/await
6. Create main.ts to tie it all together
